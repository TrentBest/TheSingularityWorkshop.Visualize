Event Horizon Field — Array-First WebGPU Demo

A live GPU scene driven by the generated shared arrays. By default it uses a demonstration near/far cadence; optionally load a JSON trace generated by Renderer to drive cohort uploads from real Event Horizon bucket refresh/reuse decisions. This is not a GPU timing benchmark.
