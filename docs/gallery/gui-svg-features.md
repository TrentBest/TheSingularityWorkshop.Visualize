# Gallery recipe: GUI.SVG feature language

## What this exhibit means

The GUI.SVG feature-gallery artifact demonstrates the expressive surface of the optional SVG manifestation path, including gradients, clipping, patterns, markers, symbols, animation, filter graphs, and lighting definitions.

## Find the generated output

Open the [Visualize proof workflow](https://github.com/TrentBest/TheSingularityWorkshop.Visualize/actions/runs/39369513107), then download `gui-svg-feature-gallery` from **Artifacts**.

## Evidence boundary

This demonstrates SVG scene/feature serialization, not a production GPU backend. SVG support and browser behavior can vary; a feature definition in an artifact does not by itself prove that every browser renders it identically.

## Recipe progression

Link each visible feature to the neutral scene data that declares it and a minimal expected-output assertion. Keep optional GUI.SVG dependencies out of Visualize core.
