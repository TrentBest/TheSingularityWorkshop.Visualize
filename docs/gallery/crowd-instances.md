# Gallery recipe: crowd instances

## What this exhibit means

The deterministic Extremus crowd fixture makes instance data visible in a generated SVG and manifest.

## Find the generated output

Open the [Visualize proof workflow](https://github.com/TrentBest/TheSingularityWorkshop.Visualize/actions/runs/39369513107), then download `visualize-extremus-crowd-proof` from **Artifacts**.

## Evidence boundary

The output helps inspect the instance contract and fixture data. It does not establish a GPU crowd renderer, animation system, or performance at production scale.

## Next recipe

Connect deterministic instance data to a selected backend and verify the actual submitted instance count. Benchmark several population sizes and report CPU preparation, upload, GPU, and total frame costs separately.
